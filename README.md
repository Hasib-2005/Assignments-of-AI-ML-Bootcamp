# Data Cleaning Assignment

This project focuses on identifying and fixing common data quality issues in a dirty dataset using Python and Pandas.

## Dataset Overview

* Rows: 10,000
* Columns: 15
* Dataset Type: Employee and Customer Information Dataset

## Problems Solved

1. Missing Values
2. Duplicate Records
3. Inconsistent Text Formatting
4. Invalid Email Addresses
5. Invalid Phone Numbers
6. Date Format Issues
7. Mixed Categories
8. Salary Outliers
9. Range Violations in Age and Price
10. Noisy Reviews
11. Boolean Stored as String
12. Incorrect Data Types
13. Range Validation
14. Class Imbalance
15. Schema Validation

## How to Run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Open the notebook:

```bash
jupyter lab
```

3. Run all notebook cells.

## Before vs After

* Missing values handled
* Outliers capped using IQR
* Invalid values corrected
* Data types standardized
* Noisy text cleaned
* Class imbalance addressed
* Useless columns removed
